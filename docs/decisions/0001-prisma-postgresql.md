# ADR 0001: Prisma и PostgreSQL

- Статус: принято
- Дата: 2026-08-22

## Контекст

Приложению нужна реляционная модель для версионируемого контента, зависимостей курса, независимой памяти пользователя и связей упражнений с проверяемыми единицами знания.

## Решение

- использовать PostgreSQL как основную базу данных;
- использовать Prisma ORM 7 с PostgreSQL driver adapter;
- хранить схему, миграции, seed и сгенерированный клиент в `packages/database`;
- экспортировать один базовый `DatabaseClient` для backend-приложения;
- инкапсулировать его жизненный цикл в глобальном NestJS `DatabaseModule`;
- генерировать Prisma Client при установке зависимостей и перед сборкой;
- не коммитить сгенерированный Prisma Client.

## Последствия

- все изменения схемы оформляются миграциями;
- API зависит от `@language/database`, но предметная логика в `packages/domain` не зависит от Prisma;
- для локальной разработки нужен PostgreSQL;
- сидирование остаётся идемпотентным и может безопасно выполняться повторно;
- при переходе на другой способ подключения достаточно изменить adapter внутри `DatabaseClient`.

# ADR 0003: shadcn/ui для frontend

- Статус: принято
- Дата: 2026-08-22

## Решение

- использовать shadcn/ui в Vite-приложении;
- использовать Tailwind CSS 4, стиль `new-york`, CSS variables и Lucide icons;
- хранить компоненты в `apps/web/src/components/ui`;
- добавлять новые компоненты официальным shadcn CLI из каталога `apps/web`;
- пока не выносить UI в отдельный workspace-пакет: это имеет смысл только при появлении второго frontend-приложения.

## Последствия

- компоненты принадлежат проекту и могут изменяться вместе с продуктом;
- дизайн-токены находятся в `apps/web/src/styles.css`;
- `components.json` фиксирует настройки генератора;
- продуктовые компоненты собираются из примитивов shadcn и не размещаются в каталоге `components/ui`.

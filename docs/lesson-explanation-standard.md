# Стандарт объяснения урока

Этот документ фиксирует обязательный педагогический шаблон для объяснений курса русский → финский. Он применяется ко всем урокам, а не только к первому модулю.

## Основной принцип

Объяснение строится по направлению **«целая картина → последовательный разбор → самостоятельное применение»**.

Ученик сначала видит компактную таблицу или схему всей новой системы. Затем текст разбирает её от простого к сложному, опираясь только на материал предыдущих уроков. Новая форма не может использоваться как основание для объяснения до того, как она была введена.

## Обязательная структура

1. Первая смысловая секция содержит таблицу или компактную схему, которая показывает основную систему урока целиком.
2. После таблицы простым текстом объясняется, что показано и как читать формы.
3. Каждый следующий раздел вводит одну новую идею и имеет содержательный заголовок.
4. После правила приводятся короткие примеры вида «финская фраза → русский перевод».
5. Исключения, ограничения и частые ошибки выносятся в компактный блок важного.
6. Если разговорная форма нужна для понимания живой речи, она вводится только после нейтральной письменной формы и явно противопоставляется `kirjakieli`.

Обычная последовательность:

```text
общая таблица → объяснение модели → примеры → детали правила → примеры → важное исключение или ошибка
```

## Требования к тексту

- Один смысловой раздел объясняет одну идею.
- Порядок отвечает на вопросы: «что это?», «как образуется?», «когда используется?» и «где ошибаются?».
- Термин вводится только тогда, когда без него нельзя обойтись, и сразу объясняется обычными словами.
- Новое правило связывается с уже известным материалом, но не требует знаний из будущих уроков.
- Пример иллюстрирует только что объяснённое правило и не содержит отдельного комментария внутри блока примеров.
- Блок важного используется только для действительно значимого ограничения или типичной ошибки.
- Объяснение должно позволять построить новую форму самостоятельно, а не только запомнить готовые фразы.

## Что запрещено

- искусственное деление на «шаги»;
- служебные подписи вроде «Объяснение», «Главное», «Самопроверка» и «Контроль»;
- задания «Проверь себя» внутри объяснения — для проверки существует практика;
- повторение одной мысли разными словами без новой пользы;
- объяснение новой формы через другую ещё не введённую форму;
- примечания и разбор ошибок внутри карточки примера;
- дословное копирование русской грамматической модели, если финская конструкция устроена иначе.

## Приёмочный чек-лист

- [ ] Первая таблица даёт общую картину темы.
- [ ] Разделы можно прочитать подряд без скачков в знаниях.
- [ ] У каждого раздела одна ясная задача.
- [ ] Примеры короткие, естественные и соответствуют правилу.
- [ ] Типичные ошибки объяснены после правильной модели.
- [ ] `puhekieli` не смешивается с нейтральными формами.
- [ ] В объяснении нет самопроверок, служебных ярлыков и пояснений внутри примеров.
- [ ] После чтения ученик понимает правило образования и область употребления.

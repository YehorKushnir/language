# Language Learning App

Монорепозиторий бесплатной платформы для изучения языков. Первый курс — русский → финский.

Описание продукта находится в [docs/language-learning-app-summary.md](docs/language-learning-app-summary.md), рабочий план — в [docs/development-plan.md](docs/development-plan.md).

## Требования

- Node.js 24+
- pnpm 11+
- Docker или Podman

## Быстрый старт

```bash
pnpm install
cp .env.example .env
pnpm dev:full
```

`dev:full` поднимает PostgreSQL, применяет миграции, выполняет seed и запускает API с frontend. При последующих запусках существующая база и пользовательский прогресс сохраняются.

Если PostgreSQL уже запущена отдельно, можно использовать обычный `pnpm dev`.

После запуска:

- web: http://localhost:5173
- API: http://localhost:3000/api/v1
- OpenAPI: http://localhost:3000/docs

## Команды

```bash
pnpm dev

pnpm dev:setup
pnpm lint
pnpm typecheck
pnpm test
pnpm e2e
pnpm e2e:local
pnpm build

pnpm content:audit:mvp
pnpm publication:validate
pnpm api:smoke:production
pnpm format:check
pnpm db:validate
pnpm db:start
pnpm db:stop
pnpm db:migrate:dev
pnpm db:seed
```

`pnpm e2e:local` подготавливает локальную PostgreSQL, собирает приложения и
проверяет основные пользовательские пути в Chromium. Перед первым запуском
установите браузер командой `pnpm exec playwright install chromium`. Сценарий
создаёт изолированный тестовый аккаунт, проверяет keyboard-навигацию и WCAG с
axe, а затем удаляет аккаунт.

## Структура

```text
apps/api          NestJS API
apps/web          Vite + React + TanStack Router
packages/contracts  общие API-контракты
packages/content-schema  схемы и проверки учебного контента
packages/domain     чистая предметная логика
packages/database   Prisma-схема и клиент PostgreSQL
packages/language-fi  адаптер Voikko/WASM и педагогическая морфология
content             версионируемый контент курсов
docs                продуктовая и техническая документация
```

Frontend использует shadcn/ui и Tailwind CSS 4. Настройки генератора находятся в `apps/web/components.json`.

Личный словарь доступен на `/vocabulary`: он показывает формы слов, состояние памяти, срок повторения и поддерживает поиск и фильтры.

Подготовленные тексты доступны на `/texts`: каталог показывает долю знакомой лексики, а экран чтения сохраняет пунктуацию, позволяет открыть разбор любого слова, добавить новое значение в изучение и озвучить текст голосом устройства. Исходники текстов и токенов также проверяются перед seed.

Первый вертикальный срез включает единую статью объяснения, 11 словарных единиц и практику по всем 60 подготовленным упражнениям на формы `olla`, отрицание, вопросы и разговорный регистр. Для прохождения практики нужно правильно выполнить минимум 85% заданий — 51 из 60.

Первый модуль опубликован целиком: 16 уроков, 401 уникальная словарная единица, 960 подготовленных упражнений и 5 текстов — после уроков 4, 8, 12, 16 и в финале модуля. Каждый урок содержит объяснение, flashcard-сессию и 60 заданий; исходный набор, все ссылки и финские формы проверяются до seed, а опубликованное состояние — отдельным PostgreSQL-валидатором. Подготовленное аудио намеренно отложено на следующий контентный проход.

TanStack Router предзагружает видимые ссылки и их route-loader’ы. Общий header сохраняется между экранами, а переходы списка, частей урока, текстов, словаря и повторения используют единый короткий View Transition без промежуточного экрана загрузки.

Финская морфология работает локально через поставляемые вместе с backend WASM и словарь: доступны неоднозначный разбор слов и текстов, леммы, падежи, число, лицо, время, частицы, орфографические подсказки, предложения и переносы. Проверка упражнений использует леммы и признаки для различения опечатки, другого слова и неверной формы. Команда `pnpm content:validate` прогоняет через тот же движок все финские формы курса.

Повторение поддерживает управляемую генерацию: типизированный шаблон первого урока даёт 198 детерминированных предложений, проверяет их той же морфологией и сохраняет в глобальный Prisma-кэш. Если самое раннее просроченное знание не поддерживается генератором, API использует подготовленное упражнение.

Авторизация реализована через BetterAuth с Prisma adapter. Регистрация и вход доступны на `/sign-up` и `/sign-in`, а endpoint `/me` и упражнения принимают только действующую серверную сессию. Для production обязательно задайте собственный случайный `BETTER_AUTH_SECRET`, а также публичные `BETTER_AUTH_URL` и `WEB_ORIGIN`.

В production API проверяет обязательные переменные окружения, требует HTTPS для публичных URL, включает security-заголовки, rate limiting, `x-request-id` и структурированный HTTP-лог, скрывает Swagger и корректно завершает соединения при остановке процесса. `MEDIA_BASE_URL` позволяет заранее подключить публичный CDN/S3-домен для будущих подготовленных аудиофайлов. В настройках пользователь может выгрузить свои учебные данные или удалить аккаунт; жалоба на упражнение привязывается к собственной попытке и также входит в экспорт.

Порядок production-выпуска, readiness, резервного копирования и отката описан в [операционном runbook](docs/operations.md). CI поднимает настоящий PostgreSQL, применяет миграции, выполняет production seed, проверяет опубликованное состояние, прогоняет браузерные E2E с accessibility-аудитом и запускает собранный API smoke-тестом.

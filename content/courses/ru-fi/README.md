# Курс русский → финский

Здесь будет храниться версионируемый исходный контент курса: маршрут, уроки, лексика, тексты и шаблоны упражнений.

Номер урока не является его идентификатором. Темы используют стабильные идентификаторы, например `fi.olla.basics`.

Перед seed и публикацией контент проверяется командой:

```bash
pnpm content:validate
```

Проверка требует уникальных идентификаторов и порядка упражнений, валидных ссылок на лексику, покрытия слов упражнениями и заданного для урока объёма контента. Для подготовленных текстов дополнительно проверяются позиции токенов, точные символьные диапазоны и ссылки на значения слов. Все финские формы прогоняются через тот же морфологический движок Voikko, который работает в API; намеренные педагогические переопределения лемм попадают в отчёт. Общие схемы находятся в `packages/content-schema`.

# Курс русский → финский

Здесь хранится версионируемый исходный контент курса: маршрут, уроки, лексика, тексты и шаблоны упражнений. `module-one.ts` собирает первые 16 уроков: 407 уникальных лемм и 960 подготовленных упражнений. В `texts/` находятся пять контрольных текстов после уроков 4, 8, 12, 16 и в финале модуля.

Номер урока не является его идентификатором. Темы используют стабильные идентификаторы, например `fi.olla.basics`.

Перед seed и публикацией контент проверяется командой:

```bash
pnpm content:validate
```

Проверка требует ровно 16 последовательных уроков, уникальных идентификаторов и лемм, 60 упражнений на урок, валидных ссылок на лексику и покрытия каждого слова упражнениями. Для подготовленных текстов дополнительно проверяются контрольные точки, позиции токенов, точные символьные диапазоны и ссылки на значения слов. Все финские формы прогоняются через тот же морфологический движок Voikko, который работает в API; намеренные педагогические переопределения лемм попадают в отчёт. Общие схемы находятся в `packages/content-schema`.
